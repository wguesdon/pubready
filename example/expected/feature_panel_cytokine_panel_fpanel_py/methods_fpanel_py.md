Concentration (pg/mL) was compared between the levels of group (Healthy control, Mild disease, Severe disease) separately for each of 9 features. One test family was chosen for the whole panel: the Shapiro-Wilk test was run on each of the 27 feature-by-group samples, and because 15 of them departed from normality (P <= 0.05, or fewer than 3 values) the rank-based Kruskal-Wallis test was used for every feature. P values were adjusted across the 9 features with the Benjamini-Hochberg method; 6 features had an adjusted P (q) below 0.05. The effect size is epsilon squared. Group sizes per feature: Healthy control (n = 16), Mild disease (n = 16), Severe disease (n = 16). Drawn in Python 3.10.12 with matplotlib 3.10.9 and scipy 1.15.3.
