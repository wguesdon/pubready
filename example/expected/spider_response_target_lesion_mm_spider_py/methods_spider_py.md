Target_lesion_mm was expressed as a percentage change from each patient's own baseline, which is the first measurement in time, and drawn as one line per patient (n = 20 patients, 94 measurements). Dashed reference lines mark +20% and -30%, the RECIST 1.1 thresholds for progressive disease and for a partial response. On the change from baseline alone, 7 patient(s) reached a partial response, 8 were stable and 5 reached progressive disease. That categorisation reads the target lesion change from baseline only. A full RECIST 1.1 assessment also reads the nadir, the non-target lesions and any new lesion. The figure is descriptive, so no statistical test is applied. Drawn in Python 3.10.12 with matplotlib 3.10.9.
