Differential-expression results for 1200 features were shown as a volcano plot. Features with |log2 fold change| >= 1.0 and p <= 0.05 were called significant; 75 were up-regulated and 75 down-regulated. The differential test itself was performed upstream; this figure summarises its output. Drawn in Python 3.10.12 with matplotlib 3.10.9 and adjustText 1.4.0.
