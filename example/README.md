# Example data and test cases

These files double as documentation and as the smoke-test inputs run by
`tests/smoke_test.sh`. Each one exercises a different path through the engine.

## Datasets

### `tumor_volume.csv` — parametric path
Two groups (control, treated), one continuous outcome, both groups roughly
normal with similar variance. The `auto` test resolver picks a **Student's
two-sample t-test**.

```bash
figkit plot --recipe two_group_compare --data example/tumor_volume.csv \
  --x group --y volume --ylab "Tumor volume (mm^3)"
```

### `cytokine_pg_ml.csv` — non-parametric path
Two groups with right-skewed values (each has a high outlier). The Shapiro-Wilk
check fails, so the `auto` resolver falls back to a **Mann-Whitney U test**.

```bash
figkit plot --recipe two_group_compare --data example/cytokine_pg_ml.csv \
  --x group --y concentration --ylab "IL-6 (pg/mL)"
```

### `gene_expression.csv` — multi-group (ANOVA)
Four groups (`wt`, `het`, `ko`, `rescue`), one continuous outcome, roughly normal
with similar variance. The `auto` resolver picks a **one-way ANOVA** with
**Tukey's HSD** post hoc. Only pairwise comparisons that reach significance are
bracketed; here `wt` vs `rescue` is not significant and is left off.

```bash
figkit plot --recipe multi_group_compare --data example/gene_expression.csv \
  --x genotype --y expression --ylab "Expression (a.u.)"
```

### `twoway_response.csv` / `threeway_response.csv` — factorial ANOVA
Two-way (`genotype` × `treatment`) and three-way (`genotype` × `treatment` ×
`sex`) designs, each with a built-in interaction. Parametric Type II ANOVA by
default; the **aligned rank transform** (ARTool) is used when the residuals are
non-normal or when forced with `--test art`. Every effect's p-value is shown on
the figure. `--fill` is the second factor, `--facet` the third.

```bash
figkit plot --recipe factorial_anova --data example/twoway_response.csv \
  --y response --x genotype --fill treatment --ylab "Response (a.u.)"

figkit plot --recipe factorial_anova --data example/threeway_response.csv \
  --y response --x genotype --fill treatment --facet sex --ylab "Response (a.u.)"
```

Both datasets are generated by `tools/make_examples/make_factorial_data.R` (seeded, so they
are deterministic).

### `survival_trial.csv` — survival analysis
A two-arm clinical-trial-style dataset: `time`, `event` (1 = event, 0 =
censored), `arm`, and covariates `age`, `sex`, `stage`. The treated arm survives
longer (log-rank significant).

Kaplan-Meier curves with the log-rank p-value and a number-at-risk table:

```bash
figkit plot --recipe survival_km --data example/survival_trial.csv \
  --time time --event event --x arm --xlab "Months"
```

Cox proportional-hazards forest plot of hazard ratios:

```bash
figkit plot --recipe cox_forest --data example/survival_trial.csv \
  --time time --event event --covariates "arm,age,sex,stage"
```

Generated by `tools/make_examples/make_survival_data.R` (seeded).

### `expression_matrix.csv` / `expression_annotation.csv` — clustered heatmap
A 30-feature by 20-sample expression matrix (matrix CSV: first column = feature
id, remaining columns = samples) plus a sample annotation table (`control` vs
`treated`). Rows are z-scored and both axes clustered. Because the annotation has
two groups, each feature gets a Welch t-test (BH-adjusted) and significant
features are starred.

```bash
figkit plot --recipe heatmap --data example/expression_matrix.csv \
  --annotation example/expression_annotation.csv
```

Generated by `tools/make_examples/make_heatmap_data.R` (seeded). Genes 1-20 are
differentially expressed by construction; 21-30 are not.

### `correlation_xy.csv` — correlation scatter
Two co-expressed genes (`gene_a`, `gene_b`) with a clear positive association.
Both variables are roughly normal, so the `auto` resolver picks **Pearson**; force
Spearman or Kendall with `--test`. The figure is a scatter with a linear fit, a
95% CI band, and the coefficient and p annotated.

```bash
figkit plot --recipe correlation --data example/correlation_xy.csv \
  --x gene_a --y gene_b
```

### `correlation_vars.csv` — clustered correlation heatmap
A panel of eight cytokines with two correlated blocks, a pro-inflammatory set
(`il6`, `tnf`, `crp`, `il1b`, `ifng`) and an anti-inflammatory set (`il10`,
`tgfb`, `il4`). The recipe correlates the numeric columns, clusters them on both
axes, and prints each coefficient with BH-adjusted significance stars.

```bash
figkit plot --recipe correlation_heatmap --data example/correlation_vars.csv
```

Both files are generated by `tools/make_examples/make_correlation_data.R` (seeded).

### `set_membership.csv` — UpSet plot
A binary membership matrix: 80 genes (first column) across four pathway sets
(`apoptosis`, `inflammation`, `metabolism`, `cell_cycle`), each cell 1 or 0. The
UpSet plot shows every observed intersection size; it is descriptive, so no test
is run. Generated by `tools/make_examples/make_upset_data.R` (seeded).

```bash
figkit plot --recipe upset --data example/set_membership.csv
```

### Prism theme, raincloud, and bar
Any of the comparison recipes accept `--theme prism` for the GraphPad Prism look
(ggprism in R, a matched matplotlib style in Python), and `--geom raincloud` or
`--geom bar` (mean + SEM + individual points).

```bash
figkit plot --recipe two_group_compare --data example/tumor_volume.csv \
  --x group --y volume --theme prism
figkit plot --recipe two_group_compare --data example/tumor_volume.csv \
  --x group --y volume --geom raincloud
```

### `de_results.csv` — volcano plot
A small synthetic differential-expression table (1200 genes, 150 truly
differential) shaped like a DESeq2 result. Columns `gene`, `log2FoldChange`,
`pvalue`, `padj`. Threshold on the adjusted p to call significance:

```bash
figkit plot --recipe volcano --data example/de_results.csv \
  --y padj --ylab "-log10 adjusted p"
```

Generated deterministically by `tools/make_examples/make_volcano_data.R` (base R,
seeded), so it is cheap to regenerate and keeps the repo light. For the genuine
airway RNA-seq benchmark (Himes et al. 2014, GSE52778, real DESeq2 results with
HGNC symbols), run the optional `tools/make_examples/make_volcano_airway.R` and
point the recipe at the `de_results_airway.csv` it writes.

### `enrichment_results.csv` — enrichment dot plot
A clusterProfiler-style ORA table (`Description`, `GeneRatio`, `Count`,
`p.adjust`) of 20 pathways. Dot size is the gene count, color the adjusted p; an
`NES` column would switch it to a GSEA dot plot. Generated by
`tools/make_examples/make_enrichment_data.R` (seeded).

```bash
figkit plot --recipe enrichment_dot --data example/enrichment_results.csv
```

### `paired_response.csv` — paired comparison
22 subjects measured `pre` and `post`, one row per measurement, connected by
`subject`. Treatment lowers the value, so the paired t-test is significant.
Generated by `tools/make_examples/make_paired_data.R` (seeded).

```bash
figkit plot --recipe paired_compare --data example/paired_response.csv \
  --x condition --y value --id subject
```

### `response_by_arm.csv` — proportions
Raw patient rows with `arm` (control, treated) and `response` (responder,
non-responder). The treated arm responds more often, so the chi-square test is
significant. Generated by `tools/make_examples/make_proportions_data.R` (seeded).

```bash
figkit plot --recipe proportions --data example/response_by_arm.csv \
  --x arm --y response
```

### `pca_samples.csv` — PCA scatter
36 samples by 40 features with a `group` column (healthy, mild, severe) built
around two latent axes, so the groups separate on PC1/PC2. The recipe draws 95%
ellipses and a PERMANOVA p. Generated by `tools/make_examples/make_pca_data.R` (seeded).

```bash
figkit plot --recipe pca --data example/pca_samples.csv --group group
```

### `spider_response.csv` — spider plot
20 patients in two arms, with the sum of target lesion diameters in millimetres
at weeks 0, 8, 16, 24 and 32. One row is one measurement, and the file holds 94
of them. The control arm grows and five of its ten patients cross the +20% line.
The treated arm shrinks and seven of its ten cross the -30% line. Three patients
stop after week 16, so the file carries the dropout that a trial always has. The
recipe expresses every value as a percentage change from that patient's own
baseline and draws one line per patient. It runs no test. Generated by
`tools/make_examples/make_spider_data.R` (seeded).

```bash
figkit plot --recipe spider_response --data example/spider_response.csv \
  --x week --y target_lesion_mm --id patient --group arm
```

## Config

### `edited_config.yaml` — render path
A hand-edited `plot_config.yaml` that switches the geometry to a violin, sets a
custom palette, and uses a numeric p-value label. Regenerate the figure without
rerunning the whole conversation:

```bash
figkit render --config example/edited_config.yaml
```

This file deliberately uses an unquoted `y:` key to cover the YAML 1.1 quirk
where a bare `y` is read as a boolean. The reader normalizes it.

## Expected results

| Input                 | Test chosen                 | Significant            |
|-----------------------|-----------------------------|------------------------|
| `tumor_volume.csv`     | Student's two-sample t-test | yes                   |
| `cytokine_pg_ml.csv`   | Mann-Whitney U test         | yes                   |
| `gene_expression.csv`  | One-way ANOVA + Tukey HSD   | 5 of 6 pairs          |
| `twoway_response.csv`  | Two-way ANOVA               | both effects + interaction |
| `threeway_response.csv`| Three-way ANOVA             | 3 main + 1 interaction |
| `survival_trial.csv`   | Kaplan-Meier + log-rank / Cox | log-rank P = 0.007; treated HR 0.54 |
| `expression_matrix.csv`| Clustered heatmap + per-feature Welch t-test | 20 of 30 features |
| `correlation_xy.csv`   | Pearson correlation         | r = 0.71, P < 0.001   |
| `correlation_vars.csv` | Pearson correlation heatmap | two clustered blocks  |
| `set_membership.csv`   | UpSet (descriptive)         | 15 intersections      |
| `de_results.csv`       | Volcano (FDR + fold change) | 150 significant genes  |
| `enrichment_results.csv`| Enrichment dot (ORA)       | 15 terms shown        |
| `paired_response.csv`  | Paired t-test               | P < 0.001             |
| `response_by_arm.csv`  | Chi-squared test            | P = 0.018, OR 2.39    |
| `pca_samples.csv`      | PCA + PERMANOVA             | F = 28, P = 0.001     |
| `spider_response.csv`  | Spider (descriptive)        | 7 PR, 5 PD, 8 stable  |
| `edited_config.yaml`   | (same as tumor_volume)      | yes                   |

Every recipe is generated by both engines; the Python bundles reuse the same
stamps with a `_py` suffix, so the R and Python versions sit side by side.
