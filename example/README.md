# Example data and test cases

These files double as documentation and as the smoke-test inputs run by
`tests/smoke_test.sh`. Each one exercises a different path through the engine.

## Datasets

### `tumor_volume.csv` — parametric path
Two groups (control, treated), one continuous outcome, both groups roughly
normal with similar variance. The `auto` test resolver picks a **Student's
two-sample t-test**.

```bash
figkit plot --recipe two_group_compare --data example/tumor_volume.csv \
  --x group --y volume --ylab "Tumor volume (mm^3)"
```

### `cytokine_pg_ml.csv` — non-parametric path
Two groups with right-skewed values (each has a high outlier). The Shapiro-Wilk
check fails, so the `auto` resolver falls back to a **Mann-Whitney U test**.

```bash
figkit plot --recipe two_group_compare --data example/cytokine_pg_ml.csv \
  --x group --y concentration --ylab "IL-6 (pg/mL)"
```

### `gene_expression.csv` — multi-group (ANOVA)
Four groups (`wt`, `het`, `ko`, `rescue`), one continuous outcome, roughly normal
with similar variance. The `auto` resolver picks a **one-way ANOVA** with
**Tukey's HSD** post hoc. Only pairwise comparisons that reach significance are
bracketed; here `wt` vs `rescue` is not significant and is left off.

```bash
figkit plot --recipe multi_group_compare --data example/gene_expression.csv \
  --x genotype --y expression --ylab "Expression (a.u.)"
```

### `twoway_response.csv` / `threeway_response.csv` — factorial ANOVA
Two-way (`genotype` × `treatment`) and three-way (`genotype` × `treatment` ×
`sex`) designs, each with a built-in interaction. Parametric Type II ANOVA by
default; the **aligned rank transform** (ARTool) is used when the residuals are
non-normal or when forced with `--test art`. Every effect's p-value is shown on
the figure. `--fill` is the second factor, `--facet` the third.

```bash
figkit plot --recipe factorial_anova --data example/twoway_response.csv \
  --y response --x genotype --fill treatment --ylab "Response (a.u.)"

figkit plot --recipe factorial_anova --data example/threeway_response.csv \
  --y response --x genotype --fill treatment --facet sex --ylab "Response (a.u.)"
```

Both datasets are generated by `tools/make_examples/make_factorial_data.R` (seeded, so they
are deterministic).

### `survival_trial.csv` — survival analysis
A two-arm clinical-trial-style dataset: `time`, `event` (1 = event, 0 =
censored), `arm`, and covariates `age`, `sex`, `stage`. The treated arm survives
longer (log-rank significant).

Kaplan-Meier curves with the log-rank p-value and a number-at-risk table:

```bash
figkit plot --recipe survival_km --data example/survival_trial.csv \
  --time time --event event --x arm --xlab "Months"
```

Cox proportional-hazards forest plot of hazard ratios:

```bash
figkit plot --recipe cox_forest --data example/survival_trial.csv \
  --time time --event event --covariates "arm,age,sex,stage"
```

Generated by `tools/make_examples/make_survival_data.R` (seeded).

### `expression_matrix.csv` / `expression_annotation.csv` — clustered heatmap
A 30-feature by 20-sample expression matrix (matrix CSV: first column = feature
id, remaining columns = samples) plus a sample annotation table (`control` vs
`treated`). Rows are z-scored and both axes clustered. Because the annotation has
two groups, each feature gets a Welch t-test (BH-adjusted) and significant
features are starred.

```bash
figkit plot --recipe heatmap --data example/expression_matrix.csv \
  --annotation example/expression_annotation.csv
```

Generated by `tools/make_examples/make_heatmap_data.R` (seeded). Genes 1-20 are
differentially expressed by construction; 21-30 are not.

### `correlation_xy.csv` — correlation scatter
Two co-expressed genes (`gene_a`, `gene_b`) with a clear positive association.
Both variables are roughly normal, so the `auto` resolver picks **Pearson**; force
Spearman or Kendall with `--test`. The figure is a scatter with a linear fit, a
95% CI band, and the coefficient and p annotated. A Spearman or a Kendall
scatter has no line.

```bash
figkit plot --recipe correlation --data example/correlation_xy.csv \
  --x gene_a --y gene_b
```

### `correlation_vars.csv` — clustered correlation heatmap
A panel of eight cytokines with two correlated blocks, a pro-inflammatory set
(`il6`, `tnf`, `crp`, `il1b`, `ifng`) and an anti-inflammatory set (`il10`,
`tgfb`, `il4`). The recipe correlates the numeric columns, clusters them on both
axes, and prints each coefficient with BH-adjusted significance stars.

```bash
figkit plot --recipe correlation_heatmap --data example/correlation_vars.csv
```

Both files are generated by `tools/make_examples/make_correlation_data.R` (seeded).

### `set_membership.csv` — UpSet plot
A binary membership matrix: 80 genes (first column) across four pathway sets
(`apoptosis`, `inflammation`, `metabolism`, `cell_cycle`), each cell 1 or 0. The
UpSet plot shows every observed intersection size; it is descriptive, so no test
is run. Generated by `tools/make_examples/make_upset_data.R` (seeded).

```bash
figkit plot --recipe upset --data example/set_membership.csv
```

### Prism theme, raincloud, and bar
Any of the comparison recipes accept `--theme prism` for the GraphPad Prism look
(ggprism in R, a matched matplotlib style in Python), and `--geom raincloud` or
`--geom bar` (mean + SEM + individual points).

```bash
figkit plot --recipe two_group_compare --data example/tumor_volume.csv \
  --x group --y volume --theme prism
figkit plot --recipe two_group_compare --data example/tumor_volume.csv \
  --x group --y volume --geom raincloud
```

### `de_results.csv` — volcano plot
A small synthetic differential-expression table (1200 genes, 150 truly
differential) shaped like a DESeq2 result. Columns `gene`, `log2FoldChange`,
`pvalue`, `padj`. Threshold on the adjusted p to call significance. The
`--ylab` value starts with "-", so it uses the `--ylab=VALUE` form:

```bash
figkit plot --recipe volcano --data example/de_results.csv \
  --y padj "--ylab=-log10 adjusted p"
```

Generated deterministically by `tools/make_examples/make_volcano_data.R` (base R,
seeded), so it is cheap to regenerate and keeps the repo light. For the genuine
airway RNA-seq benchmark (Himes et al. 2014, GSE52778, real DESeq2 results with
HGNC symbols), run the optional `tools/make_examples/make_volcano_airway.R` and
point the recipe at the `de_results_airway.csv` it writes.

### `enrichment_results.csv` — enrichment dot plot
A clusterProfiler-style ORA table (`Description`, `GeneRatio`, `Count`,
`p.adjust`) of 20 pathways. Dot size is the gene count, color the -log10 adjusted p; an
`NES` column would switch it to a GSEA dot plot. Generated by
`tools/make_examples/make_enrichment_data.R` (seeded).

```bash
figkit plot --recipe enrichment_dot --data example/enrichment_results.csv
```

### `paired_response.csv` — paired comparison
22 subjects measured `pre` and `post`, one row per measurement, connected by
`subject`. Treatment lowers the value, so the paired t-test is significant.
Generated by `tools/make_examples/make_paired_data.R` (seeded).

```bash
figkit plot --recipe paired_compare --data example/paired_response.csv \
  --x condition --y value --id subject
```

### `response_by_arm.csv` — proportions
Raw patient rows with `arm` (control, treated) and `response` (responder,
non-responder). The treated arm responds more often, so the chi-square test is
significant. Generated by `tools/make_examples/make_proportions_data.R` (seeded).

```bash
figkit plot --recipe proportions --data example/response_by_arm.csv \
  --x arm --y response
```

### `pca_samples.csv` — PCA scatter
36 samples by 40 features with a `group` column (healthy, mild, severe) built
around two latent axes, so the groups separate on PC1/PC2. The recipe draws 95%
ellipses and a PERMANOVA p. Generated by `tools/make_examples/make_pca_data.R` (seeded).

```bash
figkit plot --recipe pca --data example/pca_samples.csv --group group
```

### `spider_response.csv` — spider plot
20 patients in two arms, with the sum of target lesion diameters in millimetres
at weeks 0, 8, 16, 24 and 32. One row is one measurement, and the file holds 94
of them. The control arm grows and five of its ten patients cross the +20% line.
The treated arm shrinks and seven of its ten cross the -30% line. Three patients
stop after week 16, so the file carries the dropout that a trial always has. The
recipe expresses every value as a percentage change from that patient's own
baseline and draws one line per patient. It runs no test. Generated by
`tools/make_examples/make_spider_data.R` (seeded).

```bash
figkit plot --recipe spider_response --data example/spider_response.csv \
  --x week --y target_lesion_mm --id patient --group arm
```

### Waterfall plot (`spider_response.csv`)
The same 20 patients drawn as one bar each, from the largest growth on the left
to the deepest shrinkage on the right. Each bar is the best change from the
patient's own baseline over the visits after it, so the categories match the
spider plot.

```bash
figkit plot --recipe waterfall --data example/spider_response.csv \
  --x week --y target_lesion_mm --id patient --group arm
```

### Dose-response curves (`dose_response.csv`)
A cell viability assay with three compounds, eight 3-fold concentrations from
0.003 to 10 uM and three replicate wells at each concentration. Viability falls
with the dose, so each curve reports an IC50. The recipe fits a four-parameter
logistic curve to each compound and tests whether one shared IC50 fits as well
as one IC50 per compound. Generated by `tools/make_examples/make_dose_response_data.R`
(seeded).

```bash
figkit plot --recipe dose_response --data example/dose_response.csv \
  --x concentration_um --y viability_pct --group compound \
  --xlab "Concentration (uM)" --ylab "Viability (%)"
```

### ROC curves (`biomarker_roc.csv`)
60 patients with the disease and 80 healthy controls, measured with two serum
markers. The outcome levels sort with `healthy` second, so the command names the
case level with `--positive disease`. Generated by
`tools/make_examples/make_roc_data.R` (seeded).

```bash
figkit plot --recipe roc_curve --data example/biomarker_roc.csv \
  --y status --x marker_a,marker_b --positive disease
```

### Bland-Altman agreement (`method_agreement.csv`)
40 samples measured with a reference assay and a new assay. The new assay reads
about 3% high plus a constant, so the plot shows a bias and a small proportional
bias. Generated by `tools/make_examples/make_agreement_data.R` (seeded).

```bash
figkit plot --recipe bland_altman --data example/method_agreement.csv \
  --x new_assay --y reference_assay
```

### Meta-analysis forest plot (`meta_trials.csv`)
Nine trials that each report a hazard ratio with its 95% CI. The recipe pools
them on the log scale with a fixed-effect and a DerSimonian-Laird random-effects
model. Generated by `tools/make_examples/make_meta_data.R` (seeded).

```bash
figkit plot --recipe forest_meta --data example/meta_trials.csv \
  --y hazard_ratio --ci_low ci_low --ci_high ci_high --label trial \
  --xlab "Hazard ratio (95% CI, log scale)"
```

### Repeated-measures time course (`tumor_growth.csv`)
Tumour volume in three arms of eight mice, measured on days 0 to 21. One vehicle
mouse has no day 21 value, so the mixed ANOVA drops it and records the drop. The
growth curves violate sphericity, so the time effect and the interaction carry
the Greenhouse-Geisser correction. Generated by
`tools/make_examples/make_timecourse_data.R` (seeded).

```bash
figkit plot --recipe timecourse --data example/tumor_growth.csv \
  --x day --y volume_mm3 --id mouse --group arm \
  --xlab "Day" --ylab "Tumour volume (mm^3)"
```

### Swimmer plot (`swimmer_patients.csv`)
24 patients in two arms, one row per patient, with the months on treatment, a
status column (`ended`: 1 = the treatment ended, 0 = ongoing), and the months of
the first response and of progression. Each patient is one bar. An arrow marks
an ongoing course, and the symbols mark the two events. Generated by
`tools/make_examples/make_swimmer_data.R` (seeded).

```bash
figkit plot --recipe swimmer --data example/swimmer_patients.csv \
  --id patient --time months --event ended --group arm \
  --markers response_month,progression_month --xlab "Months on treatment"
```

### Distribution (`distribution.csv`)
The file holds the area of 240 single cells in three culture conditions. The
control cells are close to normal. The serum-starved cells are right-skewed, and
the mixed culture is bimodal. The recipe draws one histogram panel for each
condition, with a kernel density and a normal fit. The stats table gives the
Shapiro-Wilk test of each condition. The file comes from
`tools/make_examples/make_distribution_data.R`, which uses a fixed seed.

```bash
figkit plot --recipe distribution --data example/distribution.csv \
  --x condition --y cell_area_um2 --xlab "Cell area (um^2)"
```

### Composition (`composition.csv`)
The file holds the cell-type counts of 12 blood samples from a single-cell
experiment, 6 control and 6 treated. The treated samples hold more CD8 T cells
and fewer B cells. The recipe draws one 100% stacked bar for each sample and
compares each cell type between the conditions with the Mann-Whitney U test. The
file comes from `tools/make_examples/make_composition_data.R`, which uses a fixed
seed.

```bash
figkit plot --recipe composition --data example/composition.csv \
  --id sample --x cell_type --y n_cells --group condition
```

### Interaction plot (`twoway_response.csv`)
The two-way design of the factorial example, drawn as an interaction plot. Each
treatment has one line across the genotypes, with the mean +/- SEM of each cell.
The ANOVA is the same as for the box geom.

```bash
figkit plot --recipe factorial_anova --data example/twoway_response.csv \
  --y response --x genotype --fill treatment --ylab "Response (a.u.)" --geom interaction
```

### Estimation plot (`estimation_plot.csv`)
A wound-healing assay with one migration speed for each well. The file holds 14
vehicle wells and 10 to 12 wells for each of three compounds. The levels sort
with `vehicle` last, so the command names the reference with `--ref vehicle`.
Compound B slows the cells, compound A has a small effect whose CI reaches zero,
and compound C has no effect. The figure is a Cumming plot. Generated by
`tools/make_examples/make_estimation_plot_data.R`, which sets a seed.

```bash
figkit plot --recipe estimation_plot --data example/estimation_plot.csv \
  --x treatment --y speed_um_h --ref vehicle --ylab "Migration speed (um/h)"
```

The paired data of `paired_response.csv` give the Gardner-Altman layout with a
slopegraph:

```bash
figkit plot --recipe estimation_plot --data example/paired_response.csv \
  --x condition --y value --id subject --paired --ref pre
```

### Enzyme kinetics (`enzyme_kinetics.csv`)
The initial rate of an enzyme at eight substrate concentrations, in triplicate,
with no inhibitor and with a competitive inhibitor at 2 and 10 uM. A competitive
inhibitor raises the apparent Km and keeps Vmax. The shared-Km test is
therefore significant, and the shared-Vmax test is not. Generated by
`tools/make_examples/make_enzyme_kinetics_data.R`, which sets a seed.

```bash
figkit plot --recipe enzyme_kinetics --data example/enzyme_kinetics.csv \
  --x substrate_um --y rate --group inhibitor \
  --xlab "Substrate (uM)" --ylab "Rate (nmol/min/mg)"
```

### Standard curve (`standard_curve.csv`)
A sandwich ELISA plate read at 450 nm. Eight standards in duplicate, a blank and
a two-fold series from 0.156 to 10 ng/mL, follow a four-parameter logistic
curve. The 20 serum samples have an empty concentration, and the recipe reads
them off the curve. Two samples are below the lowest standard and one is above
the highest, so the recipe flags them and gives them no concentration. Generated
by `tools/make_examples/make_standard_curve_data.R`, which sets a seed.

```bash
figkit plot --recipe standard_curve --data example/standard_curve.csv \
  --x conc_ng_ml --y absorbance --id sample \
  --xlab "IL-6 (ng/mL)" --ylab "Absorbance at 450 nm"
```

### Cumulative incidence of competing risks (`cumulative_incidence.csv`)
200 patients after a stem cell transplant, in a standard arm and an intensified
arm of 100 patients each. The status is 1 for a relapse, 2 for a death without
relapse and 0 for a censored patient. The intensified arm has fewer relapses and
more deaths without relapse. The times are rounded to 0.1 month, so some event
times are tied. Generated by `tools/make_examples/make_cumulative_incidence_data.R`
(seeded).

```bash
figkit plot --recipe cumulative_incidence --data example/cumulative_incidence.csv \
  --time months --event status --x arm --xlab "Months after transplant"
```

### Calibration of two risk models (`calibration.csv`)
500 patients of a validation cohort with a one-year event (`event_1y`: yes or no)
and the predicted risks of two models. `risk_clinical` is well calibrated.
`risk_extended` was overfitted, so its predictions are too extreme and its
calibration slope is below 1. Generated by
`tools/make_examples/make_calibration_data.R` (seeded).

```bash
figkit plot --recipe calibration --data example/calibration.csv \
  --y event_1y --x risk_clinical,risk_extended --positive yes
```

### Sankey diagram of response transitions (`sankey.csv`)
80 patients with a response category at weeks 8, 16 and 24, one row per patient
visit. Most patients with progressive disease leave the study, so the later
visits hold fewer patients. The command sets the clinical order of the
categories with `--levels`. Without it, the categories keep the order of their
first appearance in the data. With three visits the diagram is descriptive.
Generated by `tools/make_examples/make_sankey_data.R` (seeded).

```bash
figkit plot --recipe sankey --data example/sankey.csv \
  --id patient --x week --y response --xlab "Week" \
  --levels "complete response,partial response,stable disease,progressive disease"
```

### MA plot (`de_basemean.csv`)
A synthetic DESeq2 table of 6,000 genes with the `baseMean`, `log2FoldChange`,
`pvalue` and `padj` columns. The standard error falls with the mean count, so
the low-count genes spread wide and seldom reach significance. The 76 genes with
a mean count below 5 have no adjusted p, as DESeq2 filters them, and the recipe
counts them as not significant. Generated by
`tools/make_examples/make_de_basemean_data.R` (seeded).

```bash
figkit plot --recipe ma_plot --data example/de_basemean.csv
```

### Manhattan and QQ plot (`gwas_summary.csv`)
Synthetic summary statistics for 20,000 SNPs on the 22 autosomes and
chromosome X, with the chromosome lengths of GRCh38 and a "chr" prefix on the
chromosome names. Four loci pass the genome-wide line, and one locus on
chromosome 15 passes only the suggestive line. Generated by
`tools/make_examples/make_gwas_summary_data.R` (seeded).

```bash
figkit plot --recipe manhattan --data example/gwas_summary.csv \
  --group chr --x pos --y p --label snp
```

### Feature panel (`cytokine_panel.csv`)
Nine serum cytokines in 16 subjects of each of three groups, in long form. The
values are log-normal, so the Shapiro-Wilk check rejects normality and every
cytokine gets the Kruskal-Wallis test. Six cytokines rise with the disease and
three do not. Generated by `tools/make_examples/make_cytokine_panel_data.R`
(seeded).

```bash
figkit plot --recipe feature_panel --data example/cytokine_panel.csv \
  --x group --y concentration_pg_ml --facet cytokine --ylab "Concentration (pg/mL)"
```

### Embedding (`umap_clusters.csv`)
A synthetic UMAP of 2,590 blood cells in eight cell types, in the shape of the
PBMC 3k data. The file holds the cell barcode, the two coordinates, the cell
type and a numeric cluster id, as a Seurat export does. The two T-cell types
touch, so their silhouette widths are lower. Generated by
`tools/make_examples/make_umap_clusters_data.R` (seeded).

```bash
figkit plot --recipe embedding --data example/umap_clusters.csv \
  --x UMAP_1 --y UMAP_2 --group cell_type
```

## Config

### `edited_config.yaml` — render path
A hand-edited `plot_config.yaml` that switches the geometry to a violin, sets a
custom palette, and uses a numeric p-value label. Regenerate the figure without
rerunning the whole conversation:

```bash
figkit render --config example/edited_config.yaml
```

This file deliberately uses an unquoted `y:` key to cover the YAML 1.1 quirk
where a bare `y` is read as a boolean. The reader normalizes it.
