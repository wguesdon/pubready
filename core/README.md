# core

The recipe library. Each recipe is a named function with a fixed argument
surface, mirrored across the R and Python engines so a scientist gets the same
figure and stats from either.

Planned subfolders:

- `r/` — R recipes built on ggpubr, rstatix, ggprism.
- `python/` — Python recipes built on matplotlib/seaborn, pingouin,
  statannotations.

See [../PRD.md](../PRD.md) for the recipe catalog and argument conventions.
